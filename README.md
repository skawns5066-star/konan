# 设备故障解决指南 (설비 오류 해결 가이드)

공장 설비의 오류를 사진과 함께 등록해 두고, 같은 오류가 다시 생기면 검색해서 해결 방법을 바로 보는 **완전 오프라인** 데스크톱 프로그램입니다. (Python + PySide6, UI 언어: 중국어 간체)

## 주요 기능
- **시작 화면**: `控制PC问题` / `检测程序PC问题` 큰 버튼 2개
- **控制PC**: 제목 실시간 검색(대소문자 무시·부분 일치) → 목록 → 큰 캡처 사진 → `解决方法` 펼치기. 사진 추가 시 **OCR로 제목 자동 입력**(수정 가능)
- **检测程序PC**: 사진 카드 3열×2행(창을 가득 채움), 페이지 넘김(`1 / 3`), 카드 클릭 시 확대 가능한 원본 + 해결 방법. 이 화면에 들어가면 창이 자동으로 커지고, 홈으로 돌아가면 원래 크기로 복귀
- **크롭 편집**: 비율 고정 박스 이동/크기 조절, 프리셋(16:9 / 4:3 / 1:1 / 自由), "不裁剪，完整放入"(여백 처리), 실시간 미리보기. 원본은 따로 보관
- **수정·삭제는 비밀번호 필요** (초기 비밀번호 `0812`, 설정에서 변경)
- **글자 크기 조절**(설정) · 모든 글자는 검은색
- 사진은 원본 경로가 아니라 `data/images/` 로 **복사**되어 저장 → 폴더째 옮겨도 동작

## 폴더 구조
```
main.py            진입점
app/               프로그램 코드 (db, storage, ocr, backup, theme, ui/…)
fonts/             Noto Sans SC/TC (OFL) - 간체 UI + 번체 제목이 깨지지 않도록 포함
data/              (실행 시 자동 생성) guide.db + images/original, images/cropped
backups/           (가져오기 전 자동 백업)
build_exe.bat      exe 빌드 스크립트
```

## 설치 및 실행 (개발/소스 실행)
1. Python 3.10 이상 설치 (Windows, "Add Python to PATH" 체크)
2. 라이브러리 설치 (인터넷 필요, 최초 1회):
   ```
   pip install -r requirements.txt
   ```
   - OCR 엔진은 **RapidOCR(onnxruntime)** 이며 **모델이 pip 패키지에 포함**되어 있어 별도 설치 없이 오프라인으로 동작합니다. (Tesseract 설치 불필요)
3. 실행:
   ```
   python main.py
   ```
OCR 이 설치되지 않았거나 실패해도 프로그램은 정상 동작하며 제목만 직접 입력하면 됩니다.

## 다른 PC에서 Python 없이 실행 (.exe 빌드)
Windows 에서:
```
pip install -r requirements.txt pyinstaller
build_exe.bat
```
`dist\EquipmentGuide\` 폴더를 통째로 USB 등으로 옮기면 Python/인터넷 없이 `EquipmentGuide.exe` 로 실행됩니다. 데이터(`data/`)는 exe 옆에 저장되므로 **폴더째 복사 = 백업/이전** 입니다.

## 백업 / 이전
- 가장 간단한 방법: **프로그램 폴더(특히 `data/`)를 통째로 복사**
- 또는 홈 화면 `设置` → `导出备份 (zip)` / `导入备份` (가져오기는 비밀번호 필요, 가져오기 전 현재 데이터를 `backups/` 에 자동 보관)

## 사용 메모
- 사진 추가: `选择图片…` / `Ctrl+V`(스크린샷·복사한 이미지 파일) / 드래그&드롭
- 검사PC 카드 비율은 설정에서 변경 가능(기본 16:9). 변경하면 보관된 원본에서 카드 사진이 자동 재생성됩니다.
- 비밀번호를 잊었다면 `data/guide.db` 의 `settings` 테이블에서 `password` 행을 삭제하고 재실행하면 `0812` 로 초기화됩니다.
