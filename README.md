# 设备故障解决指南 (설비 오류 해결 가이드)

공장 설비의 오류를 사진과 함께 등록해 두고, 같은 오류가 다시 생기면 검색해서 해결 방법을 바로 보는 **완전 오프라인** 데스크톱 프로그램입니다. (Python + PySide6, UI 언어: 중국어 간체)

## 주요 기능
- **시작 화면**: 4개 카테고리 — `条状控制PC问题` / `单颗控制PC问题` / `Sorter控制PC问题` / `检测程序PC问题`
- **4개 카테고리 모두 동일한 화면**: 제목 실시간 검색(대소문자 무시·부분 일치), 사진 카드 3열×2행(창을 가득 채움), 페이지 넘김(`1 / 3`), 카드 클릭 시 확대 가능한 원본 + 해결 방법. 카테고리 화면에 들어가면 창이 자동으로 커지고, 홈으로 돌아가면 원래 크기로 복귀
- **사진 추가**: 파일 선택 / `Ctrl+V` / 드래그&드롭 → **크롭 편집**(비율 고정 박스, 16:9·4:3·1:1·自由, "不裁剪，完整放入", 미리보기). 원본은 따로 보관. 제목은 직접 입력(번체 중국어)
- **수정·삭제는 비밀번호 필요** (초기 `0812`, 설정에서 변경 — 모든 PC에 공유됨)
- **글자 크기 조절**(설정, PC별) · 모든 글자는 검은색
- **다중 PC 동기화**(아래 참고)

## 다중 PC 동기화 (8대 이상)
방식: **공유 폴더(NAS 또는 공유 PC의 폴더)**. 별도 서버·DB 프로그램이 필요 없습니다.

1. 모든 PC가 접근 가능한 폴더를 하나 정합니다. (예: `\\NAS\guide`, 또는 드라이브 매핑 `Z:\guide`) — 읽기/쓰기 권한 필요
2. 각 PC에서 `设置` → `多台PC数据同步` 에 **같은 경로**를 입력하고 `应用并立即同步`
3. 이후 자동으로 동작합니다.
   - **자동 동기화**: 항목을 추가·수정·삭제하면 약 0.5초 뒤 공유 폴더에 올리고, 설정한 주기(5/10/30/60초)마다 다른 PC의 변경을 받아와 화면에 반영
   - **수동 동기화**: `自动同步` 체크를 끄면 자동으로는 아무것도 하지 않고, 화면 우측 상단/하단의 `⟳ 同步` 버튼을 눌렀을 때만 일괄 갱신
   - 상태 표시: `● 已同步 12:03:11（↑1 ↓2）` (올린 개수/받은 개수), 연결 불가 시 오류 + 대기 중인 수정 개수

동작 원리 / 특징
- 각 PC는 자기 `data/` 에 **전체 사본**을 가지므로 공유 폴더(네트워크)가 끊겨도 계속 사용할 수 있고, 연결되면 밀린 변경을 자동으로 올립니다.
- 공유 폴더에는 `entries/<id>.json`(항목 1개=파일 1개), `images/`, `settings.json` 이 생깁니다. SQLite 파일 자체를 네트워크에 두지 않으므로 DB 손상 위험이 없습니다.
- 공유되는 것: 항목(제목·해결 방법·사진·크롭), **비밀번호, 카드 비율**. PC별로 유지되는 것: 글자 크기, 공유 폴더 경로.
- **충돌**: 두 PC가 같은 항목을 거의 동시에 수정하면 더 나중(수정 횟수→시각 기준)의 수정이 남습니다. 삭제도 다른 PC로 전파됩니다.
- 처음 연결할 때 PC마다 이미 가진 항목은 합쳐집니다(중복 제거 없음, 서로 다른 항목으로 취급).
- PC 시계가 크게 다르면 동시 수정 시 우선순위가 어긋날 수 있으니 시간 동기화를 권장합니다.

## 폴더 구조
```
main.py            진입점
app/               프로그램 코드 (db, storage, sync, backup, theme, ui/…)
fonts/             Noto Sans SC/TC (OFL) - 간체 UI + 번체 제목이 깨지지 않도록 포함
data/              (실행 시 자동 생성) guide.db + images/original, images/cropped
backups/           (가져오기 전 자동 백업)
build_exe.bat      exe 빌드 스크립트
```

## 설치 및 실행 (개발/소스 실행)
1. Python 3.10 이상 설치 (Windows, "Add Python to PATH" 체크)
2. 라이브러리 설치 (인터넷 필요, 최초 1회):
   ```
   pip install -r requirements.txt
   ```
   - 필요한 라이브러리는 PySide6 하나뿐입니다. (OCR 기능은 제거되었습니다)
3. 실행:
   ```
   python main.py
   ```

## 다른 PC에서 Python 없이 실행 (.exe 빌드)
Windows 에서:
```
pip install -r requirements.txt pyinstaller
build_exe.bat
```
`dist\EquipmentGuide\` 폴더를 통째로 USB 등으로 옮기면 Python/인터넷 없이 `EquipmentGuide.exe` 로 실행됩니다. 데이터(`data/`)는 exe 옆에 저장되므로 **폴더째 복사 = 백업/이전** 입니다.

## 백업 / 이전
- 가장 간단한 방법: **프로그램 폴더(특히 `data/`)를 통째로 복사**
- 또는 홈 화면 `设置` → `导出备份 (zip)` / `导入备份` (가져오기는 비밀번호 필요, 가져오기 전 현재 데이터를 `backups/` 에 자동 보관)

## 사용 메모
- 사진 추가: `选择图片…` / `Ctrl+V`(스크린샷·복사한 이미지 파일) / 드래그&드롭
- 카드 비율은 설정에서 변경 가능(기본 16:9). 변경하면 보관된 원본에서 카드 사진이 자동 재생성됩니다.
- 이전 버전의 `控制PC` 데이터는 자동으로 `条状控制PC` 로 옮겨집니다.
- 백업 가져오기를 하면 가져온 내용이 공유 폴더의 기존 내용보다 우선하여 다른 PC에도 반영됩니다.
- 비밀번호를 잊었다면 `data/guide.db` 의 `settings` 테이블에서 `password` 행을 삭제하고 재실행하면 `0812` 로 초기화됩니다.
